아이디·비밀번호를 알려주실 필요는 없습니다. (스토어 약관상 계정 공유는 금지라서, 초대 방식이 안전합니다.)

**1. 구글 플레이 (안드로이드) — 등록비 $25, 평생 1회**

① https://play.google.com/console 접속 → 구글 계정으로 로그인
② "개발자 계정 만들기" → **개인(Personal)** 선택
③ 이름·주소·연락처 입력 후 신분증으로 본인확인 (며칠 걸릴 수 있습니다)
④ $25 결제
⑤ 완료되면 왼쪽 메뉴 **사용자 및 권한** → **새 사용자 초대**
   → 이메일 `여기에_내_이메일` 입력, 권한은 **관리자**로 설정 → 초대

**2. 애플 (아이폰) — 연 $99, 매년 갱신**

※ 아이폰 버전은 나중에 해도 됩니다. 급하지 않으시면 구글부터 하셔도 좋습니다.

① https://developer.apple.com/programs/ 접속 → Apple ID로 로그인
② "Enroll" → **Individual** 선택
③ $99 결제
④ 완료되면 https://appstoreconnect.apple.com → **사용자 및 액세스**
   → **+** 버튼 → 이메일 `여기에_내_이메일`, 역할 **App Manager** → 초대

**3. 그 외에 필요한 것**

- 앱 이름으로 쓸 정식 명칭 (지금은 "BIKE LOOP"로 되어 있습니다)
- 개인정보 처리방침을 올릴 웹페이지 — 없으시면 제가 만들어드릴 수 있습니다
- 문의용 이메일 주소 (스토어에 공개로 표시됩니다)

**4. 미리 알려드릴 일정**

구글은 신규 개인 계정의 경우 **정식 출시 전에 테스터 12명이 14일간 앱을 써보는 과정**을 요구합니다.
즉 계정 만든 뒤에도 **최소 2주**가 더 필요합니다. 출시 목표일이 있으시면 미리 알려주세요.

## Ⅱ. 참고 — 내부용 메모 (보내지 말 것)

### 왜 초대 방식인가

- 계정 공유는 Google Play / Apple 양쪽 약관 위반. 적발 시 계정 정지 → 앱 삭제
- 초대 방식이면 의뢰자가 소유권(과금·명의)을 갖고, 나는 업로드·수정만 수행
- 나중에 관계가 정리돼도 앱은 의뢰자에게 남음 (분쟁 소지 없음)

### 개인 계정이라서 생기는 제약

| 항목 | 개인 | 사업자/법인 |
|---|---|---|
| 구글 12명·14일 테스트 | **필수** | 면제 |
| 스토어 표시 이름 | 실명 노출 | 기관명 노출 |
| 애플 D-U-N-S | 불필요 | 필요(1~2주) |

→ 만약 의뢰처가 학교·기관·회사라면 **사업자/법인 계정을 강하게 권장**.
   12명 테스터 모으는 일이 생각보다 큰 부담이고, 기관명 노출이 대회·홍보에도 유리하다.

### 내가 이어서 해야 할 일 (초대 받은 뒤)

1. 릴리스 서명키(keystore) 생성 → **절대 분실 금지**, Play 앱 서명 활성화
2. 패키지명 확정 (현재 `com.example.bike_reclaim` 이면 반드시 변경 — 한 번 정하면 못 바꿈)
3. 카카오 개발자 콘솔에 **릴리스 키 해시** 등록 (안 하면 출시본에서 지도 안 뜸)
4. AAB 빌드 (`flutter build appbundle --release`)
5. 스토어 등록 정보: 아이콘 512×512, 스크린샷, 설명, 데이터 안전 양식
6. **심사용 테스트 계정** 준비 (관리자 로그인 정보 — 없으면 심사 반려)
7. 개인정보 처리방침 웹 게시
8. 위치기반서비스사업 신고 (위치정보법, 위치정보지원센터 https://www.lbsc.kr/)
9. iOS는 Mac 필요 → Codemagic 등 클라우드 빌드 검토
